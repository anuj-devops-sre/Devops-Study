# 🚀 Project 01: 3-Tier Application with Docker Compose

A hands-on project to deploy a full-stack application using Docker.

## 🏗️ Architecture
1.  **Frontend**: React/Angular application.
2.  **Backend**: Node.js/Python API.
3.  **Database**: PostgreSQL/MySQL.

## 📂 Structure
- `frontend/`: Dockerfile and source code for the UI.
- `backend/`: Dockerfile and source code for the API.
- `db-init/`: SQL scripts for database initialization.

## 🛠️ Usage
```bash
docker-compose up -d
```
