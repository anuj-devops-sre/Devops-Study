# ⚙️ CI/CD with Jenkins & Ansible

## 🚀 Jenkins
- **Pipelines as Code**: Using Groovy-based Jenkinsfiles.
- **Nodes/Agents**: Scaling builds across multiple machines.

## 📜 Ansible
Agentless configuration management.
- **Playbooks**: YAML files defining the desired state.
- **Inventory**: List of managed nodes.
