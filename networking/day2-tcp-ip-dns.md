# 🌐 Day 2: TCP/IP & DNS

## 📦 TCP/IP Suite
- **TCP (Transmission Control Protocol)**: Connection-oriented, reliable.
- **UDP (User Datagram Protocol)**: Connectionless, fast.
- **IP (Internet Protocol)**: Routing and addressing.

## 🔍 DNS (Domain Name System)
How the internet maps human-readable names to IP addresses.
- Records: A, AAAA, CNAME, MX, TXT, NS.
- Resolution process: Recursive vs. Iterative.
