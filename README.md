# 🚀 Devops-Study: The Ultimate SRE & Platform Engineering Path

This repository is a structured, hands-on roadmap for mastering DevOps and Site Reliability Engineering. It covers everything from fundamentals to advanced production-grade infrastructure.

## 🗺️ Master Study Guides (Single-File Deep Dives)
For easier learning, all technical notes have been consolidated into single "Master" files:

*   ☁️ **[AWS SRE Master Guide](./aws/AWS-SRE-MASTER-NOTES.md)**: IAM, EC2, VPC, S3, RDS, and Cost Optimization.
*   ☸️ **[Kubernetes SRE Master Guide](./kubernetes/K8S-SRE-MASTER-NOTES.md)**: Workloads, Scaling, Security (IRSA/RBAC), and Multi-cluster.
*   🐳 **[Docker & Container Mastery](./docker/container-mastery.md)**: Optimization, Multi-stage builds, and Security.
*   🏗️ **[Terraform Mastery](./terraform/terraform-mastery.md)**: Modules, Remote State, and State Locking.
*   🔄 **[CI/CD & Automation](./ci-cd/cicd-mastery.md)**: Jenkins, GitHub Actions, and Deployment Strategies.
*   📊 **[Observability Master Guide](./monitoring/OBSERVABILITY-SRE-MASTER-NOTES.md)**: Prometheus, Grafana, Loki, and Golden Signals.
*   🛡️ **[DevSecOps Mastery](./security/security-mastery.md)**: Secrets management, IaC scanning, and Falco.
*   🤝 **[SRE Culture & Incidents](./SRE-CULTURE-MASTERI.md)**: SLOs, Error Budgets, and Post-Mortems.
