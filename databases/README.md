# 🗄️ Databases

This section covers various database systems used in DevOps and SRE workflows.

## 📂 Database Types

### Relational (SQL)
- **[PostgreSQL](./postgresql.md)**: Advanced open-source relational database.
- **[MySQL](./postgresql.md)**: Widely used relational database (currently sharing notes with PostgreSQL).

### NoSQL & Caching
- **[Redis](./redis.md)**: In-memory data structure store, used as a database, cache, and message broker.
- **[MongoDB](./redis.md)**: Document-oriented NoSQL database (notes coming soon).

### OLAP & Big Data
- **[ClickHouse](./clickhouse.md)**: Fast open-source column-oriented database management system for online analytical processing (OLAP).
